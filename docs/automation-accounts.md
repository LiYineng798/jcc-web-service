# AI 自动化账号

由管理员在「用户管理 → AI 自动化账号」创建，普通注册始终创建普通用户，不能选择此角色。
账号使用正常登录页的用户名与密码登录，随后进入 `/admin` 的协作工作台。
前台账号菜单和登录页都保留后台入口。密码至少 12 字符，包含字母和数字，只存哈希；不提供专用 API 令牌。

## 权限

- 默认只读：运营概览、按日期复制排行、已生成日报、公开普通赛季阵容。复制排行包含上传者。
- 运营数据按明确字段筛选，不展示邮箱、IP、逐次访问/复制人员明细、审计日志或系统配置。
- 可单独授权「普通阵容批量导入」，并选择赛季。页面先预览再确认，每批最多 50 行、20000 字符；重复内容跳过，作者记录为当前账号。不能覆盖、删除、隐藏、调分或审核阵容。
- 可单独授权「榜单更新时间」，并选择赛季。只能设为服务器当前时间，不能提交任意日期、替换阵容或发布版本；操作写入审计。
- 用户管理、公告、审核、资料包、实时榜单内容发布、系统设置都不可用。即使直接请求管理员路径或普通用户写入路径也会拒绝。
- 所有工作台写入要求登录会话和 CSRF；服务端每次校验角色、状态、有效期、操作及赛季范围。读取每分钟最多 60 次，写入每小时最多 10 次（包括导入预览）。

## 生命周期

管理员设置账号有效期（1–90 天，默认 30 天），可以续期、调整权限、重设密码、禁用和删除。
禁用/删除立即使已有登录失效；重新启用需要重新登录。重设密码也使旧登录失效。
删除采用停用并保留归属记录的方式，已上传阵容及操作审计保留。
账号不参与普通用户增长指标，不开放普通找回邮件；密码由管理员重设。

## 升级

先应用 DB 迁移，再部署 Web。`0024_automation_sessions.sql` 将旧令牌版结构转换为会话权限结构，
删除令牌字段和导入回执表；SQLite 启动迁移执行同等转换。历史迁移保留以保证升级链完整。
旧版本自动化账号需要管理员设置登录密码后才能使用，原有令牌失效。
工作台使用站内会话请求；旧 `/api/automation/*` 和令牌轮换入口已经移除。
