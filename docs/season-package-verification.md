## 截图与运行限制

浏览器截图保存在不提交的 `instance/season-package-checks/`：`chromium-upload.png`、`webkit-upload.png` 和各宽度/主题文件。手机验收以实际滚动及视口为准；现有底部导航的延伸绘制会覆盖全页截图的视口外部分。

完整生命周期的最新截图保存在 `instance/season-lifecycle-checks/`，分别包含 Chromium/WebKit 的 initial、update、hotfix 发布状态。该目录同样不入 Git。

初版使用单台 Web 主机的持久目录、独立 worker 和完整 ZIP，不支持断点续传、自动删除历史、跨节点文件分发或后台添加全新模拟器能力。静态基准不是独立历史包，首次启用应先将当前静态资料打包发布以保留初始快照。详见操作手册。
