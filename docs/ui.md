# 前端维护要点

模块映射见 [架构](architecture.md)，构建见 [React 工程](../frontend/README.md)，
执行方式见 [开发与验证](development.md)。这里只记录不容易从页面表面看出的约束。

## 共享能力

- `templates/seo_head.html` 在主样式前恢复主题，并加载 `notifications.js/css`。
- 短暂反馈走共享通知；消息写入 textContent，保留内联表单错误、任务进度和危险操作确认。
  剪贴板成功立即反馈，统计失败不能被误报为复制失败；dialog 内通知必须能关闭。
- `avatar.js` 用一个带 evenodd 镂空的 SVG 路径绘制固定条纹球体，避免恢复 Safari 有问题的 mask/blur。
  DB 只存六位颜色，不存上传图、SVG 或外部 URL。
- 公开详情保留服务端文本；首页搜索/翻页使用 API 结果，缓存命中不闪骨架，失败/取消请求不滚动到列表。
- `/#guestbook` 打开当前页留言弹窗；公告链接的留言跳转优先于旧阵容跳转字段。
- 手机后台固定栏使用安全区和实色背景；只在需要的页面开启 viewport-fit，不能用设备地址栏高度猜布局。

## 后台

`admin.js` 管导航、状态和请求，`static/admin/` 子模块管具体工作区。保存响应是权威结果，
后续刷新失败不能把已经成功的写入报成失败；通知过期不触发整页重绘。

`season-picker.js` 在插入 DOM 后同步挂载，每次渲染前销毁旧实例。缓存命中或连续渲染会发生在同一事件循环，
不能用 setTimeout + 全局 ID 绑定，否则一次点击会被重复切换。标签使用独立 for，
保留键盘、触控外部关闭、焦点恢复以及切换赛季后的文件/文本。

资料库与模拟器共用 `season-display.js`，各自排序/可见性独立；实时阵容仍有独立分类。
只有 active/archived 有连续公开序号，隐藏/停用不能排序，恢复追加到末尾，默认项失效时回退到首个公开项。

审计 React 列表不取 before/after 大字段；详情按需取并递归脱敏。筛选计数表示全部历史，
操作者名称来自当前账号，历史快照可能不对称，不把缺字段推断成删除。
数值 target_id 与文本 target_key 都保留。

## 个人中心

`bento-card.tsx` 管栏目，`account-dialogs.tsx` 管页内通知/处理详情/编辑，`account-api.ts` 管可取消请求，
`static/account.js` 连接既有 API 与复制历史。切栏目、离页时取消旧请求；失败不伪装成零值。

编辑和嵌套浮窗保留原栏目、搜索、页码、草稿、焦点及返回路径。
`/me#avatar` 打开共享头像编辑器，`/me#lineup-notifications` 打开本地通知浮窗。
主页通知仍打开独立作者详情页。待审不可编辑，不可用旧赛季必须重新选择；
通知只标记实际渲染的 revision，审核/编辑保留乐观版本检查，见 [审核规则](lineup-moderation.md)。

## 模拟器与活动页

模拟器和实时站位图使用普通图片节点与内层裁切容器，避免单独 clip-path、3D transform 或祖先 drop-shadow
引发 Safari 合成错位。宽图/海报导出的头像和羁绊等级框保留真实 img，便于导出器嵌入。
调整棋盘结构时验证页面、宽图和海报。

固定 S16.5 开局效果与代码在 `lucky_openings.py`，不是普通弈子技能。图片读取当前公开资料 release；
隐藏资料库时保留文本但不读取隐藏图片。它不写普通/实时复制统计。
S8 静态工具的内容与图片留在本仓库，不依赖协调目录素材。
