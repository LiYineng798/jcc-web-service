# S18 18.2 官方资料更新

本地赛季档案和 Web 发布数据从 18.18.1c 更新到 18.18.2（mode=18，官方 season=S19）。

来源： https://game.gtimg.cn/images/lol/act/jkzlk/js/18/18.18.2-S19/ 。使用官方 chess/race/job/equip/adventure/hex 数据及腾讯图片，不访问 DataTFT。Web 导入增加 `--official-only`，跳过 DataJ 回合统计。官方仙灵不提供 rounds/requires；本版按用户要求，从本地 18.18.1c 归档沿用 170 条回合和 55 条使用条件，未访问 DataTFT。按 ID、名称及官方变体 ID 匹配，extensions.provenance 明确标记继承版本、影响字段及尚未验证本补丁；强化符文缺少出现时机时保留空列表。

## 重建

在 `ccmax资料/数据模板` 执行：

```powershell
python scripts/import_existing_seasons.py --season s18 --version 18.18.2
python scripts/validate.py --all
```

在 Web 仓库执行：

```powershell
python scripts/season_library/import_from_archive.py --season s18 --official-only
python -m pytest -q
```

档案保留旧快照，Web 目录只发布默认版本。检查下载报告无失败、来源无旧快照回退、图片完整及 board_units.discovery_audit。

本次不改变数据库表、业务记录或实时排行榜；无需数据库迁移。赛季资料由 Web 静态 JSON 和图片承载。用户负责推送 GitHub 和后续部署，本次未修改服务器。

部署前备份数据库及当前站点版本；将 JSON 和图片一同发布，重启 jcc.service，然后检查 /api/health、/tools/seasons/s18、弈子详情和 /tools/lineup-simulator。赛季 JSON 缓存必须重新验证。回滚时恢复旧默认快照并重建、部署，不能仅替换 catalog。
