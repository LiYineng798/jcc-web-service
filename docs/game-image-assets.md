# 游戏素材图片资源目录

公告正文中可以直接引用以下服务器已有图片，写 `<img>` 标签即可渲染。

## 引用方式

所有图片的基础路径为：

```
/static/tools/lineup-simulator/blur/webp/
```

示例：

```html
<img src="/static/tools/lineup-simulator/blur/webp/mode17s18_hero_by_cost_cn/price-5/烬.webp" alt="烬" style="max-width:100%;border-radius:8px;" />
```

## 使用建议

1. 在公告正文中直接写 HTML `<img>` 标签
2. 建议统一加 `style="max-width:100%;border-radius:8px;"` 保证响应式和风格统一
3. 可搭配 `<p>`、`<h3>` 等标签组织结构
4. 如果需要的图片不在上述目录中，可以联系站长上传到服务器 `static/` 目录下
