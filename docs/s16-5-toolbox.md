# S16.5 恭喜发财开局推荐与工具箱

主页原来的「S8回归信息差」下拉入口改为与「资料库」同级的「工具箱」。新工具箱优先展示 S16.5 开局推荐，并在 S8 分组下保留特殊机制、神器搭配指南、回归装备三个原有入口。桌面用可点击、键盘可操作的原生 details；Escape 和点击外部可关闭。手机沿用「资料与工具」底部弹层，将两个赛季的攻略放在同一工具箱分组。

## 推荐页

公开路由：`GET /tools/s16-5-lucky-openings`。页面服务器渲染，游客可直接使用；已有 sitemap 收录新页面，日报用 `lucky_openings` 标记访问。

- 九张固定卡片依照提供的阵容码顺序展示：阿兹尔、稻草人、卢锡安、希瓦娜、基兰、安妮、千珏、杰斯、奥恩。稻草人的正式名称为费德提克，卢锡安使用资料库中的卢锡安与赛娜图片。
- 每张卡片展示图片、名称、五费标识、活动效果标题、完整效果和复制操作。数值加粗，不展示羁绊。共同的「玩家对战回合」条件移至页面顶部，其余效果文字保持完整。
- 宽屏三列；760px 及以下两列，包含 320px 窄屏。卡片可自然变高，效果不截断；每行复制按钮对齐，触控高度至少 44px。
- 延续全站暖色、深浅主题；金色点缀与「福」字装饰由 CSS 和系统字体绘制，无额外字体、React 或图片生成依赖。

## 数据与复制约定

`lucky_openings.py` 保存本次用户提供的九条代码和四张「福气临门」海报文字。这是独立的人工整理内容，不是资料库普通技能，也不应随资料库技能文本自动覆盖。后续调整效果或阵容码时应核对新的来源材料并同步测试。

复制结果使用 `lineup_code.extract_lineup_code`，与后台 `parse_bulk_lineup_entries` 一致，规范化为 `#MjIw…`，不包含「【阵容码】」前缀和阵容名称。九条输入与后台解析结果逐项对照测试。游戏内的导入与阵容有效性仍需人工验收。

复制先调用 Clipboard API，再尝试旧浏览器复制方式；失败时自动展开并选中代码，给出全站统一提示。「查看阵容码」可随时手动展开，禁用 JS 时也能使用。固定推荐不写入用户阵容表、不调用普通阵容或实时阵容的复制统计接口。

## 图片与性能

图片通过 `season_reference_service.champion_summaries()` 和 `season_data_repository.asset_url()` 读取 S16.5 当前公开资料库版本，优先用现成的 500×255 WebP 卡图。没有复制图片文件，也没有改动自动生成的赛季数据。缓存沿用资料库按版本目录隔离的索引缓存，版本发布后重新解析新图片地址，页面不另设永久缓存。

前三张图片正常加载，其余延迟加载；固定图片比例防止布局跳动。首页只加载工具箱菜单所需的小量 CSS/JS，不渲染九张卡片、加载卡图或加载推荐页脚本。图片加载失败时保留深色底、姓名、机制和复制入口。若管理员隐藏 S16.5 资料库，推荐页保留固定文本和代码，但不请求隐藏图片或显示资料库链接。

## 本地预览与验收

在当前 worktree 运行：

```powershell
python tests/serve_lucky_openings_preview.py
```

默认 `http://127.0.0.1:5105/`，推荐页 `http://127.0.0.1:5105/tools/s16-5-lucky-openings`。可用 `OPENINGS_PREVIEW_PORT` 改变预览端口。脚本为预览创建临时 SQLite 和运行文件，关闭后台 worker，不读取生产数据库；首页实时阵容列表为空属于隔离预览的正常情况。

验证命令：

```powershell
python -m pytest -q
node tests/lucky_openings_rendering.cjs
```

浏览器命令需要 `NODE_PATH` 提供 Playwright，并在预览服务运行时执行。覆盖 Chromium/WebKit、320/390/520/768/1440px、浅色/深色、双列与按钮边界、菜单边界、真实 Chromium 剪贴板、两种复制失败降级、移动端入口、主题持久化、禁用 JS；截图输出到被忽略的 `instance/lucky-openings-checks/`。真实手机 Safari 和游戏客户端最终导入效果可在用户验收时补充确认。

此次仅变更 Web 仓库，无数据库迁移或新的生产环境变量。用户验收前保留在 `codex/s16-5-toolbox`，不合并 main、不发布生产。

2026-09-12 本地验证：Web 全量 `python -m pytest -q` 通过 614 项；最终复制与主题调整后，5 项专属 Python 测试以及 Chromium/WebKit 浏览器检查均通过。视觉复核修正了窄屏菜单越界、推荐页主题切换绑定，以及新页面主题 SVG 在 WebKit 中需要带单位几何属性的问题。九张现成 WebP 合计 104,908 字节，工具箱 CSS/JS 合计 2,141 字节（均为未压缩文件大小）。
